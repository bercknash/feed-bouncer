# Privacy policy: Feed Ad Hider for Facebook

Last updated: 13 November 2026

Feed Ad Hider does not collect, transmit, sell, or share any data.

- **No network requests.** The extension contains no code that contacts any server. Everything
  it does happens inside your browser, on the Facebook tab you have open.
- **What it reads.** To tell which posts are sponsored, it reads information Facebook has already
  loaded into the page: the feed's sponsored-post flag and the "Sponsored" / "Ad" label on each
  post. This is used in the moment to decide whether to hide a post and is not stored or sent
  anywhere.
- **What it stores.** Four on/off settings (enabled, hide suggested posts, show placeholder,
  debug), saved with Chrome's `storage.sync` so they follow your Chrome profile. Counts shown in
  the popup are kept in memory for the current tab only and are discarded when the tab closes.
- **No analytics, no ads, no accounts, no remote code.**

Feed Ad Hider is not affiliated with, endorsed by, or sponsored by Meta Platforms, Inc.
Facebook is a trademark of Meta Platforms, Inc.
